# Lapka

Неофициальное веб-приложение, которое возвращает к жизни датчики **Lapka Personal Environment Monitor**
(Radiation, EMF, Humidity, Organic). Они подключались к iPhone через разъём наушников. Теперь работают в Chrome
на компьютере и Android: через гнездо для гарнитуры или переходник USB-C → 3.5 мм с микрофоном.

**Открыть:** https://mooneyed.github.io/lapka/

Работа с датчиками перенесена на JavaScript (Web Audio) из SenseFramework —
[lapka-pem-sdk-ios](https://github.com/duhovny/lapka-pem-sdk-ios) Сергея Филиппова: тон 16–19 кГц
в двух каналах, определение датчика по 4-битному коду, калибровка и коэффициенты оригинала.
Без датчика можно попробовать демо-режим с виртуальным датчиком.

## Как пользоваться
1. Вставьте датчик, поставьте громкость системы на максимум. Наушники не надевайте: на выходе громкий ультразвуковой тон.
2. Нажмите «Начать» и разрешите микрофон. Тип датчика определится автоматически.
3. Если датчик не распознаётся, откройте «Настройки → Диагностика».
